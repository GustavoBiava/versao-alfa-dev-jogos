# Versão Alfa - Desenvolvimento de Jogos

Este repositório contém o protótipo inicial do nosso projeto de jogo em 2D.

* **Status do Projeto:** Trata-se de uma **Versão Alfa** inicial e de testes, não refletindo a qualidade, os gráficos ou o conteúdo da versão final.
* **Objetivo Principal:** O foco exclusivo desta etapa é **validar as mecânicas fundamentais** de gameplay.
* **Mecânicas Validadas:**
  * Sistema de movimentação e colisão.
  * Coleta e gerenciamento de itens no inventário (Ex: Parafina, Martelo).
  * Interação do jogador com o cenário (Ex: Destruir a passagem bloqueada).
  * Exibição de mensagens de UI dinâmicas e contextuais.
* **O que não esperar agora:** Polimento visual avançado, efeitos sonoros, menu principal ou level design completo.
* **Controles Básicos:**
  * `W, A, S, D` ou `Setas`: Movimentar o personagem.
  * `E` ou `Espaço`: Interagir com o cenário (após coletar os itens necessários).
